# OneTouch Remote Prototype

This module contains a minimal prototype:
- WebRTC DataChannel/WSS message receiver (`ControlChannelManager.kt`)
- AccessibilityService executor (`RemoteControlAccessibilityService.kt`)
- Onboarding activity and persistent notification (`OnboardingActivity.kt`, `ControlSessionService.kt`)
- Encrypted audit log utility (`AuditLog.kt`)

Manifest snippets and Gradle dependencies should be integrated into the main app.
